For developers

A wait-time API is coming.

We already normalize official airport feeds into a clean shape — checkpoint, lane type, wait, capture time, and a freshness label. A documented, key-authenticated API to read it is on the roadmap so you can build it into your own product.

GET /v1/airports/{code}/current      # standard + precheck, per checkpoint
GET /v1/airports/{code}/history      # 30-day hourly pattern
GET /v1/airports                     # network snapshot
Authorization: Bearer YOUR_KEY       # planned

This sketch is illustrative, not a live endpoint. Want early API access? Tell us what you'd build and we'll reach out when it opens.
